# 📱 Megaline Plans Analysis - Comportamento de Clientes e Receita

Projeto desenvolvido no bootcamp da **TripleTen** para analisar o comportamento de utilização de clientes de uma empresa de telecomunicações (*Megaline*) e determinar qual dos planos pré-pagos (*Surf* ou *Ultimate*) gera mais receita.

## 🚀 Tecnologias Utilizadas
- **Python** (Pandas, NumPy, Matplotlib, Seaborn)
- **Estatística Descritiva e Inferencial** (`scipy.stats`)
- **Jupyter Notebook**

## 🎯 Objetivos do Projeto
- **Pré-processamento e Enriquecimento:** Limpeza de dados de chamadas, mensagens e tráfego de internet, conversão de tipos (datas), arredondamento de durações de chamadas por regras de negócio e cálculo do consumo mensal por utilizador.
- **Análise Exploratória (AED):** Estudo estatístico (média, variância e desvio padrão) do uso de minutos, mensagens e dados móveis em cada plano. Visualização de distribuições com histogramas e diagramas de caixa (*boxplots*).
- **Teste de Hipóteses:** Validação estatística de hipóteses sobre a igualdade de receitas médias entre os planos e entre diferentes regiões (ex: NY-NJ vs outras cidades).

## 💡 Principais Conclusões
A análise permitiu identificar padrões claros de consumo e rentabilidade entre os dois planos, fornecendo dados acionáveis para o departamento comercial ajustar o orçamento de publicidade e focar nas campanhas mais lucrativas.
